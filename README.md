A website project for a fictional beauty business offering professional beauty and self-care services.

## 2. Project Overview

Glow Beauty Studio is a fictional beauty business created for the WEDE5020 Web Development project. The business offers professional beauty and self-care services in a welcoming and inclusive environment for customers from different backgrounds.

The website provides customers with information about the business, its services, prices, contact details and enquiry options. It aims to create a professional, attractive and user-friendly online experience.

## 3. Goals and Objectives

The main goal of the Glow Beauty Studio website is to create a professional online presence for the business.

The objectives are to:

- Introduce the business and its services.
- Display beauty services, descriptions and prices.
- Encourage customer enquiries and bookings.
- Provide clear contact information.
- Create an attractive and user-friendly website.
- Ensure that customers can navigate the website easily.

## 4. Website Features and Functionality

### Home Page
- Welcome message.
- Business introduction.
- Call-to-action buttons.
- Navigation to other website pages.

### About Page
- Business history.
- Mission and vision.
- Business values.
- Team information.

### Services Page
- Makeup services.
- Eyelash services.
- Nail services.
- Skincare services.
- Service descriptions and prices.
- Service durations.
- Booking call-to-action.
- Service search functionality.

### Enquiry Page
- Customer name field.
- Email address field.
- Contact number field.
- Service selection.
- Preferred date and time.
- Message field.
- Form validation and submit button.

### Contact Page
- Business contact details.
- Email address.
- Phone number.
- Business location.
- Opening hours.
- Social media information.
- Google Maps.
- Customer feedback form.

## 5. Technologies Used

The following technologies were used to develop the website:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the website, including colours, layouts, fonts and spacing.
- **Bootstrap:** Used to support the website layout and responsive design.
- **JavaScript:** Used to add interactive features and improve website functionality.
- **GitHub:** Used to store the project files and track development changes.
