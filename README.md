## Project overview
Glow Beauty Studio is a fictional beauty business created for the WEDE5020 web development project, offering professional beauty and self-care services in a welcoming and inclusive environment for customers from different backgrounds. The website provides customers with information about the business, its services, prices, contacts details and enquiry options while creating a professional, simple and user-friendly online experience

## Goals and Objectives
The main goal of the Glow Beauty Studio website is to create a professional online presence that clearly introduces the business, showcases its beauty services and provides customers with an easy way to access important information. The objectives are to attract potential customers, display services description and prices encourage enquiries and bookings, provide clear contact information, and create a simple, attractive and user-friendly website

Glow & Grace Beauty Studio is a small beauty business website created to provide customers with information about the business, its beauty services, and how to make an enquiry. The website uses a clean, modern and luxurious design with nude and brown colours to create a warm and professional beauty studio feel.

* **Design:** Modern, feminine and professional.
